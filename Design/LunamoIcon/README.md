## LPのブランドマーク

ページ冒頭とナビゲーションには背景付きの正式なアプリアイコンを使う。セクション見出しには、同じ原画から背景だけを除いた「月とマリモ」のマークを使う。三日月（#72AC99）とマリモ（#B9DAC1）の比率・傾き・重なり・色はライト／ダークで共通。文字の月記号や他の月形には置き換えない。

`python3 Design/LunamoIcon/export-web-mark.py` で2枚のSVGレイヤーからWeb用マークを再生成する。使用箇所はCSSの `.section-title::before` に集約する。機能を識別する小アイコンは24単位・線幅1.6・丸端の線画とし、ブランドマークと役割を分ける。
